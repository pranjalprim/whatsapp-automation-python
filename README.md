# 🚀 WhatsApp Web Automation using Python & Selenium 4

An enterprise-grade, robust, and fully automated script designed to streamline WhatsApp Web operations. Built with **Python** and **Selenium 4**, this project automates sending personalized text messages and media attachments (images/documents) cleanly and efficiently.

---

## 📌 Features

* **Selenium 4 Standard Compliance:** Built using modern Selenium 4 features, including `Service` objects and `By` locators for high dynamic adaptability.
* **Text & Media Automation:** Automates end-to-end messaging—sending custom dynamic text messages and media attachments (`.jpeg`, `.png`, `.pdf`).
* **Resilient Element Locators:** Uses resilient XPath and CSS Selectors optimized for WhatsApp Web’s modern DOM updates.
* **Explicit Waits Implementation:** Utilizes `WebDriverWait` and `expected_conditions` to avoid flaky execution and ensure smooth element interactions.
* **Clean & Documented Code:** Written with modular code structuring, comprehensive logging, and line-by-line English inline comments.

---

## 🛠️ Tech Stack & Tools

* **Language:** Python 3.x
* **Automation Tool:** Selenium 4
* **Browser Driver:** ChromeDriver (Managed via Webdriver Manager / Local Path)
* **IDE/Environment:** Jupyter Notebook / VS Code
